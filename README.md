# No Ascension Tonight

今晚不飞升，Godot 4.6 游戏原型。

## 目录

- `src/autoload/`: 全局单例
- `src/components/`: 可复用组件
- `src/entities/`: 游戏实体脚本
- `src/ui/`: UI 脚本
- `src/weapons/`: 武器逻辑
- `src/tests/`: 测试场景脚本
- `scenes/entities/`: 实体场景
- `scenes/world/`: 世界与关卡场景
- `scenes/weapons/`: 武器场景
- `scenes/tests/`: 测试场景
- `assets/textures/`: 按用途整理的纹理资源
- `docs/`: 设计文档与任务记录

主入口：`scenes/tests/test_scene.tscn`
