# 游戏设计方案：今晚不飞升

## 1. 核心概念

《今晚不飞升》是一款领地生存与高频战斗成长结合的修仙 Roguelike。玩家镇守山海裂界中央的灵核，白天出门斩妖、收集四色灵性，夜晚回到灵核附近抵御妖潮，在第 20 波完成飞升。

核心取舍：

- 白天离开光环越远，获得灵性的效率越高，但回防风险越大。
- 四色灵性决定基础成长和光环形态；最低颜色限制光环基础等级。
- 属性可以单独专精，也可以携带多种属性触发反应。
- 提前挑战山门大妖可以减少后续路线压力，但会改变刷怪方向。

## 2. 设计支柱

1. **方向即策略**：四个方向对应四种颜色、四类敌群和四名大妖。
2. **进攻服务防守**：白天收集资源，夜间用构筑和站位守住灵核。
3. **单属性有深度，多属性有反应**：专精提供稳定性，组合提供上限。
4. **越早处理大妖越安全**：山门挑战会改变可用路线和后续压力。
5. **每波都有明确节奏**：刷怪预算耗尽后停止生成，战斗压力随波次递增。

## 3. 核心循环

1. **昼间，60 秒**
   - 玩家从灵核出发，在开放方向移动和战斗。
   - 击杀敌人，拾取红、绿、蓝、黄四色灵性球。
   - 灵性球同时推进颜色等级和玩家升级经验。

2. **夜间，60 秒**
   - 敌人从当前开放方向生成并向玩家或灵核中心移动。
   - 玩家在灵核光环内获得主场加成，同时处理敌人路线和属性反应。
   - 当前波次刷怪预算耗尽后停止新增敌人。

3. **波间调谐**
   - 夜间结束后暂停游戏。
   - 玩家选择下一波偏向的颜色，影响后续灵性球掉落权重。
   - 选择确认后进入下一波昼间。

4. **第 20 波飞升终局**
   - 夜间持续 90 秒。
   - 生成飞升妖王。
   - 撑过计时或击杀飞升妖王，完成本局。

## 4. 20 波节奏

| 波段 | 路线 | 重点 |
| :--- | ---: | :--- |
| 1-3 | 1 路 | 教学移动、拾取、回到灵核 |
| 4-6 | 2 路 | 混合敌型和第一次属性构筑 |
| 7-9 | 3 路 | 赤裂大妖出现，开始处理山门挑战 |
| 10-12 | 4 路 | 翠疫大妖出现，山海共鸣开始生效 |
| 13-15 | 4 路 | 蓝弧大妖出现，远程压力提高 |
| 16-19 | 4 路 | 黄砂大妖出现，终局准备 |
| 20 | 4 路 | 飞升妖王和 90 秒终局 |

当前实际数值以 `src/autoload/wave_manager.gd` 的 `WAVE_PLAN` 为准。

## 5. 世界与四方山门

中央灵核位于山海裂界中心，四座山门分别连接不同异兽巢域。四色灵性不是单纯颜色标记，而是四种攻击风格的资源来源。

| 方向 | 山门 | 颜色 | 属性 | 敌群风格 | 大妖 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 北 | 赤裂山门 | 红 | 火、爆 | 近战冲锋 | 赤裂大妖 |
| 南 | 翠疫山门 | 绿 | 毒、藤 | 腐蚀、压制 | 翠疫大妖 |
| 东 | 蓝弧山门 | 蓝 | 水、冰 | 远程、控制 | 蓝弧大妖 |
| 西 | 黄砂山门 | 黄 | 风、雷 | 高速、链击 | 黄砂大妖 |

## 6. 灵核与光环

当前原型中，灵核是地图中心、玩家回防目标和护山灵光来源，不进入普通敌人的受伤判定。

### 6.1 光环效果

- 光环内伤害 +20%。
- 光环内攻速 +20%。
- 光环内移速 +15%。
- 光环内每 5 秒回复生命。
- 玩家离开光环后，光环专属加成取消。

### 6.2 木桶原理

每 5 个同色灵性球形成 1 个颜色等级。光环基础等级取四色等级最低值：

```text
光环等级 = min(红色等级, 绿色等级, 蓝色等级, 黄色等级)
```

光环形状会根据四色数量向对应方向延展，已击败的大妖方向可以形成更长的灵路视觉。

## 7. 四色资源与八种属性

四色灵性球仍只有四种，属性标签通过武器和升级卡获得，不增加掉落种类。

| 颜色 | 属性一 | 属性二 | 属性定位 |
| :--- | :--- | :--- | :--- |
| 红 | 火 | 爆 | 灼烧、爆炸、破甲 |
| 绿 | 毒 | 藤 | 腐蚀、减速、束缚 |
| 蓝 | 水 | 冰 | 浸润、冻结、碎裂 |
| 黄 | 风 | 雷 | 扩散、位移、链击 |

### 7.1 属性状态

- **火**：灼烧，持续造成伤害。
- **爆**：爆印，等待其他属性触发爆炸。
- **毒**：中毒，持续腐蚀并降低治疗效果。
- **藤**：缠绕，降低移速并触发束缚。
- **水**：浸润，强化后续反应。
- **冰**：寒霜，减速、冻结和碎裂。
- **风**：风痕，切割并扩散附近状态。
- **雷**：雷印，触发麻痹和链式闪电。

### 7.2 属性反应

目标可以同时携带多种状态。两种状态共存时，满足反应表就会产生额外效果；反应具有独立冷却，避免无限重复触发。

| 属性组合 | 反应 | 效果 |
| :--- | :--- | :--- |
| 火 + 水 | 蒸爆 | 范围伤害、击退、短暂硬直 |
| 火 + 冰 | 熔裂 | 高额碎裂伤害 |
| 火 + 毒 | 焚毒 | 毒层瞬间爆发 |
| 火 + 藤 | 燃藤 | 追加火焰状态 |
| 火 + 雷 | 雷火 | 链式伤害 |
| 爆 + 火 | 爆燃 | 范围爆炸 |
| 爆 + 冰 | 冰爆 | 冻结并造成爆炸伤害 |
| 爆 + 雷 | 雷爆 | 链式爆炸 |
| 毒 + 冰 | 冻毒 | 毒层持续时间延长并冻结 |
| 毒 + 风 | 毒雾 | 毒素扩散 |
| 毒 + 雷 | 腐雷 | 链式腐蚀伤害 |
| 藤 + 冰 | 冰藤 | 冻结和束缚叠加 |
| 藤 + 雷 | 雷网 | 束缚目标之间传导闪电 |
| 水 + 冰 | 冰封 | 快速冻结 |
| 水 + 雷 | 导电 | 闪电跳跃 3 次 |
| 水 + 风 | 水刃 | 击退和穿透 |
| 冰 + 风 | 雪暴 | 范围减速和冰伤 |
| 冰 + 雷 | 霜雷 | 冻结目标碎裂并链击 3 次 |
| 风 + 雷 | 风雷 | 链式闪电 |

### 7.3 单属性与多属性

属性熟练度 3/6/10 点分别达到一、二、三级专精。

- 单属性专精：状态强度、持续时间、层数和反应冷却更优秀。
- 双属性构筑：一种属性挂状态，另一种属性触发反应。
- 三属性构筑：反应链更多，清群上限更高，但熟练度更分散。
- 通用副属性只改变攻速、范围、穿透、弹体数量和触发效率。

## 8. 本命武器

单局选择 1 把本命武器。当前原型提供四把：

| 武器 | 初始属性 | 攻击身份 |
| :--- | :--- | :--- |
| 引霜灵剑 | 火 | 近身灼烧与爆发 |
| 破鳞钢刃 | 毒 | 连斩叠毒与腐蚀 |
| 龙脊长枪 | 冰 | 穿透冻结与碎裂 |
| 火符连铳 | 雷 | 远程链击与麻痹 |

升级卡可以加入其他属性，形成单属性专精或多属性反应。普通成长卡提供通用副属性和基础生存属性。

## 9. 山门挑战与大妖

玩家可以在昼间进入山门 GateZone，持续站定后召唤对应大妖。击败大妖后：

- 对应大妖状态标记为已击败。
- 对应方向从后续刷怪方向中移除。
- 灵性掉落权重会重新计算。

大妖计划：

| 大妖 | 自动波次 | 提前解锁波次 |
| :--- | ---: | ---: |
| 赤裂大妖 | 7 | 5 |
| 翠疫大妖 | 10 | 8 |
| 蓝弧大妖 | 13 | 11 |
| 黄砂大妖 | 16 | 14 |
| 飞升妖王 | 20 | 20 |

第 10 波开始，每名已经出现且尚未击败的大妖提供 1 层山海共鸣，提升敌人的生命、伤害和速度。这里的“山海共鸣”是大妖压力系统，不等同于属性反应。

## 10. 敌人

当前敌人类型：

- **近战妖**：接近玩家并进行接触攻击。
- **箭妖**：远程发射弹体，迫使玩家移动。
- **魔法妖**：远程攻击，受雷火等属性反应影响明显。
- **治疗妖**：远离玩家并治疗附近妖兽，受到毒状态影响。

敌人和大妖都可以携带属性状态。冰、藤会降低移动和行动效率，毒会降低治疗，反应会造成额外伤害和控制。

## 11. UI 与失败/胜利

HUD 显示：

- 当前昼夜状态和波次。
- 当前计时。
- 四色灵性球数量。
- 玩家等级和升级经验。
- 当前属性标签与熟练度。
- 光环状态。
- 最近受到的伤害。

失败条件：玩家生命归零。

胜利条件：第 20 波撑过终局计时，或击杀飞升妖王。

## 12. 当前实现边界

本文只描述当前原型已经接入的昼夜循环、四色灵性、属性状态、属性反应、单多属性构筑、四把武器、山门挑战、20 波刷怪和终局流程。新增系统必须先更新本文，再进入代码实现。
