# 术语表

| 术语 | 定义 |
| :--- | :--- |
| 本命武器 | 每局选择并持续培养的唯一主武器，决定玩家主要攻击身份。 |
| 攻击形态 | 武器的基础攻击方式，例如横扫、突刺或弹射。 |
| 武器效果 | 修改攻击行为或触发条件的能力，例如穿透、追踪、击杀爆炸。 |
| 效果替换 | 用新效果取代已有同类效果，保持构筑取舍。 |
| 属性标签 | 附着在武器攻击上的火、爆、毒、藤、水、冰、风、雷等攻击属性。 |
| 属性反应 | 两种属性状态同时存在时触发的额外伤害、控制或扩散效果。 |
| 属性熟练度 | 单个属性的累计成长；3/6/10 点分别对应一、二、三级专精。 |
| 单属性专精 | 集中强化一种属性，换取更高状态强度和更稳定触发。 |
| 多属性构筑 | 同时携带两种或更多属性，通过属性反应获得更高战斗上限。 |
| 通用副属性 | 攻速、范围、穿透、弹体数量等不改变元素身份的 delivery 属性。 |
| 基础升级 | 直接提升生命、伤害、攻速、移速等数值的普通成长卡。 |
| 灵性 | 红、绿、蓝、黄四色资源及其对应的属性成长。 |
| 调谐 | 夜间结束时选择下一波偏向的灵性颜色，影响属性球掉落权重。 |
| 山海共鸣 | 第 10 波后由未击败大妖提供的敌方强度增益。 |
| 灵核光环 | 以灵核为中心的主场区域，范围受四色灵性最低等级影响。 |
