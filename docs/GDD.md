# 游戏设计方案：今晚不飞升 (No Ascension Tonight)

## 1. 核心概念 (Core Concept)
《今晚不飞升》是一款结合领地生存、防守压力与高频战斗成长的修仙 Roguelike。玩家是一名踏入山海秘境的修仙者，需要守住中央的“灵核/道基”，在昼间斩杀四方妖兽、掠夺四色灵性，夜间守住山门，最终在第 20 波完成飞升。

## 2. 设计支柱 (Design Pillars)
1. **方向即策略**：四个方向对应四条资源路线、四种敌人生态、四个大妖。
2. **平衡有收益，偏科有代价**：四色最低值决定基地光环半径。
3. **进攻服务防守**：昼间行动决定夜间怪潮强度和路线。
4. **斩首大妖的时机**：全局决策的核心。
5. **构筑必须互相咬合**：调谐、武器、路线和敌人反制共同决定每局打法。

## 3. 核心循环 (Game Loop)
1. **昼：远征与削弱 (60s)**：远征斩妖，掠夺灵性。
2. **转场：商店与建设 (20-30s)**：购买法宝、强化阵法、修补灵核。
3. **夜：阵地防守 (60s)**：在灵核光环内抵御妖兽冲击。
4. **飞升 (波次 20)**：终局挑战。

### 20 波执行节奏
- **1-3 波**：单路低压教学，刷怪预算 4-8 / 12-20（昼 / 夜）。
- **4-6 波**：双路构筑期，刷怪预算 10-14 / 26-38。
- **7、10、13、16 波**：依次触发赤裂、翠疫、蓝弧、黄砂四名大妖；门区分别允许提前 2 波挑战。
- **10 波起**：每名已出现且未斩首的大妖提供 1 层共鸣，敌人获得生命、伤害 +5%，速度 +3%。
- **17-19 波**：四路终局准备，高密度混合敌潮。
- **20 波**：生成飞升妖王，夜间 90 秒终局；撑过计时或击杀妖王即完成本局。
- 波次结束后不再无限刷怪；昼、夜预算耗尽即停止生成，生命、伤害、速度倍率随等级逐波上升。

### 武器成长方案 (Weapon Progression)
- **MVP**：1 把武器，3 种攻击形态，6-8 个效果，5 波流程。
- **正式版本**：6 种本命武器，单局选择 1 把；6 把是武器池，不是同时装备数量。
- **中后期**：允许 1 把主武器 + 1-2 件辅助法宝。
- **暂不做**：6 把攻击武器同时运行。
- **武器升级**：效果替换或进化，不允许无限叠加。

### 八种属性与元素反应
- 红色：火、爆；绿色：毒、藤；蓝色：水、冰；黄色：风、雷。
- 攻击先给敌人施加属性状态；不同状态组合触发不同反应，反应额外造成伤害、控制或扩散。
- 同一属性可以持续累积熟练度，获得更高状态强度；多属性构筑牺牲单项深度，换取反应上限。
- 颜色灵性球仍只有四色，不增加八种掉落物；属性通过武器、升级卡和属性熟练度获得。
- 单次攻击最多携带当前构筑已有属性；目标状态有持续时间和反应冷却，避免无限连锁。

| 颜色 | 属性 | 攻击定位 |
| :--- | :--- | :--- |
| 红 | 火、爆 | 灼烧、爆炸、破甲 |
| 绿 | 毒、藤 | 腐蚀、减速、束缚 |
| 蓝 | 水、冰 | 浸润、冻结、碎裂 |
| 黄 | 风、雷 | 扩散、位移、链式闪电 |

核心反应：火+水=蒸爆、火+冰=熔裂、火+毒=焚毒、火+藤=燃藤、毒+冰=冻毒、毒+风=毒雾、水+雷=导电、冰+雷=霜雷、藤+雷=雷网、冰+风=雪暴。

### 单属性专精与多属性构筑
- 属性熟练度 3/6/10 点分别达到一、二、三级专精。
- 单属性专精：状态更强、持续更久、触发更稳定，构筑简单且前期成型快。
- 双属性构筑：以一种属性挂状态，另一种属性触发反应，适合稳定输出。
- 三属性构筑：反应链更多，清群上限最高，但每种属性熟练度成长更慢。
- 通用升级只强化攻速、范围、穿透、弹体数量、元素触发效率等 delivery 属性，不替代元素身份。

## 4. 基地系统：灵核 (The Life Core)
- **护山灵光 (Radiation Range)**：主场加成区。
- **木桶原理 (Lowest-Level Gating)**：光环半径由四色灵性中最低等级决定。

## 5. 四大山门与大妖
- **北 (红)**：火与爆，近战冲锋，削弱大妖攻击力。
- **南 (绿)**：毒与藤，腐蚀束缚，削弱大妖最大生命。
- **东 (蓝)**：水与冰，浸润冻结，削弱大妖攻击频率。
- **西 (黄)**：风与雷，高速链击，削弱大妖移动速度。

## 6. 斩首行动 (The Beheading)
提前挑战大妖，成功后封死对应山门，减少夜间压力，但该色能量产出将受限。
