# ADR-001：单局单本命武器

- 状态：已接受
- 日期：2026-08-17

## 背景

游戏同时包含昼间远征、夜间守核、四色灵性、属性反应、山门斩首和 Roguelike 构筑。若单局同时运行多把攻击武器，玩家的攻击来源会变得混乱，移动与路线决策的重要性下降。

早期原型曾经保留 `WeaponBase -> MeleeWeapon/RangedWeapon -> ConcreteWeapon` 的继承雏形，但玩家场景实际使用的是单一运行时攻击分支，两套来源会造成参数和行为漂移。当前决策是在保留单武器规则的同时，使用 `WeaponRuntime` 作为四把武器的唯一数据契约，玩家负责执行攻击，旧继承体系不再作为兼容入口。

## 决策

- 当前提供 4 把本命武器，单局只选择 1 把。
- 本命武器自带 1 条初始属性，属性卡可以扩展攻击标签。
- 普通成长卡提供通用副属性，不改变武器的元素身份。
- 不在单局同时运行多把主攻击武器。
- 武器成长通过属性标签和通用副属性形成分支，不允许同类效果无限叠加。
- 属性反应可以作为构筑核心，但单属性专精必须具备完整收益；不以连续命中计数作为唯一核心。

## 结果

### 正向结果

- 保留玩家走位、路线和回防决策的压力。
- 单次攻击来源清晰，敌我反馈和数值更容易读取。
- 本命法宝与四色灵性、斩首收益可以形成统一主题。
- 当前内容量和测试组合可控，适合验证昼夜循环。
- 四把武器通过初始属性和攻击形态提供跨局差异。

### 代价

- 单局同时出现的攻击种类较少，需要通过攻击形态和效果分支维持变化。
- 单武器效果如果无限叠加，会失去弱点，必须限制同类效果叠加。
- 属性反应增加单武器构筑深度，但必须限制状态持续时间、反应冷却和属性熟练度上限。

## 实现边界

玩家攻击由 `WeaponRuntime` 提供的本命武器配置、属性标签和通用副属性共同组成。玩家实体负责攻击执行与场景节点复用，属性状态由目标组件管理，反应由属性组合触发；不引入多主武器槽位，也不保留旧武器继承脚本或独立武器场景作为运行入口。

## 被拒绝方案

单局同时装备多把主攻击武器不采用。该方案会削弱单武器属性构筑的决策价值，也会增加目标选择和视觉反馈成本。
