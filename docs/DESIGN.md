# 游戏设计方案：今晚不飞升

## 1. 核心概念

《今晚不飞升》是一款领地生存与高频战斗成长结合的修仙 Roguelike。玩家镇守山海裂界中央的灵核，白天出门斩妖、收集四色灵性，夜晚回到灵核附近抵御妖潮，在第 20 波完成飞升。

核心取舍：

- 白天离开光环越远，获得灵性的效率越高，但回防风险越大。
- 四色灵性决定基础成长和光环形态；最低颜色限制光环基础等级。
- 属性可以单独专精，也可以携带多种属性触发反应。
- 提前挑战山门大妖可以减少后续路线压力，但会改变刷怪方向。

## 2. 设计支柱

1. **方向即策略**：四个方向对应四种颜色、四类敌群和四名大妖。
2. **进攻服务防守**：白天收集资源，夜间用构筑和站位守住灵核。
3. **单属性有深度，多属性有反应**：专精提供稳定性，组合提供上限。
4. **越早处理大妖越安全**：山门挑战会改变可用路线和后续压力。
5. **每波都有明确节奏**：刷怪预算耗尽后停止生成，战斗压力随波次递增。

## 3. 核心循环

1. **昼间，60 秒**
   - 玩家从灵核出发，在开放方向移动和战斗。
   - 击杀敌人，拾取红、绿、蓝、黄四色灵性球。
   - 灵性球同时推进颜色等级和玩家升级经验。

2. **夜间，60 秒**
   - 敌人从当前开放方向生成并向玩家或灵核中心移动。
   - 玩家在灵核光环内获得主场加成，同时处理敌人路线和属性反应。
   - 当前波次刷怪预算耗尽后停止新增敌人。

3. **波间调谐**
   - 夜间结束后暂停游戏。
   - 玩家选择下一波偏向的颜色，影响后续灵性球掉落权重。
   - 选择颜色后，在三种波间事件中选择一项，再进入下一波昼间。

### 3.1 波间事件

- **回灵·修核**：灵核恢复 30 点，玩家恢复 20 点。
- **贪取·丰收**：下一次白天击杀有 35% 概率额外掉落一颗灵性球。
- **镇门·护阵**：下一夜灵核获得 18 秒无敌护阵。

事件只影响下一波，目的是让玩家根据当前灵核、生命和构筑状态做短期决策。

4. **第 20 波飞升终局**
   - 夜间持续 90 秒。
   - 生成飞升妖王。
   - 撑过计时或击杀飞升妖王，完成本局。

| 波段 | 路线 | 重点 |
| :--- | ---: | :--- |
| 1-3 | 1 路 | 教学移动、拾取、回到灵核 |
| 4-6 | 2 路 | 混合敌型和第一次属性构筑 |
| 7-9 | 3 路 | 赤裂大妖出现，开始处理山门挑战 |
| 10-12 | 4 路 | 翠疫大妖出现，山海共鸣开始生效 |

## 5. 世界与四方山门

中央灵核位于山海裂界中心，四座山门分别连接不同异兽巢域。四色灵性不是单纯颜色标记，而是四种攻击风格的资源来源。

第一关地图采用由正方形旋转 45° 得到的等距菱形战场：中央灵核为安全区核心，四条蜿蜒的小路向上、右、下、左四个等距尖角延伸，四个尖角分别容纳一间对应势力的 Boss 房，四个区域的面积和步行距离保持一致。小路只在中央附近保持可辨识，离开中心后逐步收窄、断续并被当地地形侵蚀，靠近 Boss 房时只留下踏石、残垣或浅淡路基，暗示长期无人深入。区域地表全部可通行，水、火和山石只作为小水洼、裂土、低矮土坡与散石点缀；菱形外侧不是硬切黑边，而是以雾海、远山和低对比度远景形成缓冲；可战斗区域的碰撞边界与菱形轮廓一致，保证视觉边界和移动边界一致。

| 方向 | 山门 | 颜色 | 属性 | 敌群风格 | 大妖 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 北 | 赤裂山门 | 红 | 火、爆 | 近战冲锋 | 赤裂大妖 |
| 南 | 翠疫山门 | 绿 | 毒、藤 | 腐蚀、压制 | 翠疫大妖 |
| 东 | 蓝弧山门 | 蓝 | 水、冰 | 远程、控制 | 蓝弧大妖 |
| 西 | 黄砂山门 | 黄 | 风、雷 | 高速、链击 | 黄砂大妖 |

## 6. 灵核与光环

当前原型中，灵核是地图中心、玩家回防目标和护山灵光来源，不进入普通敌人的受伤判定。

### 6.1 光环效果

- 光环内伤害 +20%。
- 光环内攻速 +20%。
- 光环内移速 +15%。
- 光环内每 5 秒回复生命。
- 玩家离开光环后，光环专属加成取消。

### 6.2 木桶原理

每 5 个同色灵性球形成 1 个颜色等级。光环基础等级取四色等级最低值：

```text
光环等级 = min(红色等级, 绿色等级, 蓝色等级, 黄色等级)
```

光环形状会根据四色数量向对应方向延展，已击败的大妖方向可以形成更长的灵路视觉。

### 6.3 灵核耐久

- 灵核初始耐久为 100，HUD 显示当前耐久。
- 夜间敌人抵达灵核后会按敌人类型周期性造成伤害。
- 灵核被摧毁会立即失败；护阵期间免疫灵核伤害。
- 灵核受击、修复、护阵和破碎都有独立战斗反馈。

## 7. 四色资源与八种属性

四色灵性球仍只有四种，属性标签通过武器和升级卡获得，不增加掉落种类。

| 颜色 | 属性一 | 属性二 | 属性定位 |
| :--- | :--- | :--- | :--- |
| 红 | 火 | 爆 | 灼烧、爆炸、破甲 |
| 绿 | 毒 | 藤 | 腐蚀、减速、束缚 |
| 蓝 | 水 | 冰 | 浸润、冻结、碎裂 |
| 黄 | 风 | 雷 | 扩散、位移、链击 |

### 7.1 属性状态

- **火**：灼烧，持续造成伤害。
- **爆**：爆印，等待其他属性触发爆炸。
- **毒**：中毒，持续腐蚀并降低治疗效果。
- **藤**：缠绕，降低移速并触发束缚。
- **水**：浸润，强化后续反应。
- **冰**：寒霜，减速、冻结和碎裂。
- **风**：风痕，切割并扩散附近状态。
- **雷**：雷印，触发麻痹和链式闪电。

### 7.2 属性反应

目标可以同时携带多种状态。两种状态共存时，满足反应表就会产生额外效果；反应具有独立冷却，避免无限重复触发。

| 属性组合 | 反应 | 效果 |
| :--- | :--- | :--- |
| 火 + 水 | 蒸爆 | 范围伤害、击退、短暂硬直 |
| 火 + 冰 | 熔裂 | 高额碎裂伤害 |
| 火 + 毒 | 焚毒 | 毒层瞬间爆发 |
| 火 + 藤 | 燃藤 | 追加火焰状态 |
| 火 + 雷 | 雷火 | 链式伤害 |
| 爆 + 火 | 爆燃 | 范围爆炸 |
| 爆 + 冰 | 冰爆 | 冻结并造成爆炸伤害 |
| 爆 + 雷 | 雷爆 | 链式爆炸 |
| 毒 + 冰 | 冻毒 | 毒层持续时间延长并冻结 |
| 毒 + 风 | 毒雾 | 毒素扩散 |
| 毒 + 雷 | 腐雷 | 链式腐蚀伤害 |
| 藤 + 冰 | 冰藤 | 冻结和束缚叠加 |
| 藤 + 雷 | 雷网 | 束缚目标之间传导闪电 |
| 水 + 冰 | 冰封 | 快速冻结 |
| 水 + 雷 | 导电 | 闪电跳跃 3 次 |
| 水 + 风 | 水刃 | 击退和穿透 |
| 冰 + 风 | 雪暴 | 范围减速和冰伤 |
| 冰 + 雷 | 霜雷 | 冻结目标碎裂并链击 3 次 |
| 风 + 雷 | 风雷 | 链式闪电 |

### 7.3 单属性与多属性

属性熟练度 3/6/10 点分别达到一、二、三级专精。

- 单属性专精：状态强度、持续时间、层数和反应冷却更优秀。
- 双属性构筑：一种属性挂状态，另一种属性触发反应。
- 三属性构筑：反应链更多，清群上限更高，但熟练度更分散。
- 通用副属性只改变攻速、范围、穿透、弹体数量和触发效率。

## 8. 本命武器

单局选择 1 把本命武器。当前原型提供四把：

| 武器 | 初始属性 | 攻击身份 |
| :--- | :--- | :--- |
| 引霜灵剑 | 火 | 近身灼烧与爆发 |
| 破鳞钢刃 | 毒 | 连斩叠毒与腐蚀 |
| 龙脊长枪 | 冰 | 穿透冻结与碎裂 |
| 火符连铳 | 雷 | 远程链击与麻痹 |

升级卡可以加入其他属性，形成单属性专精或多属性反应。普通成长卡提供通用副属性和基础生存属性。

### 8.1 主动诀技

玩家按空格释放本命武器对应的主动诀技，拥有独立冷却：

| 武器 | 诀技 | 战斗身份 |
| :--- | :--- | :--- |
| 引霜灵剑 | 赤焰回环 | 近身火爆范围清场与击退 |
| 破鳞钢刃 | 腐心散 | 毒藤范围压制并回复生命 |
| 龙脊长枪 | 霜锋震 | 冰水范围冻结与击退 |
| 火符连铳 | 天雷引 | 远距离锁定五个目标的雷链 |

主动诀技会附加当前构筑的属性标签，并触发已有属性反应。

### 8.2 升级卡三选一

每次升级暂停战斗并展示三张互不重复的卡片。卡片分为三层：

- **基础成长卡**：最多 III 阶，补充生命、伤害、攻速、移速、护甲、范围等稳定数值；每一阶收益递增，例如攻击伤害为 +10% / +12% / +15%。
- **属性成长卡**：最多 III 阶，属性熟练度按 +3 / +4 / +5 增长，与 3 / 6 / 10 点专精门槛衔接，推动单属性专精或多属性反应。
- **机制转折卡**：唯一解锁，改变诀技、灵核、属性反应或本命武器的战斗行为，不与基础数值卡混淆。

卡池优先保证一张机制转折卡，再从不同类别补齐基础成长和属性构筑，减少三张卡同时提供同一种收益。卡面必须同时显示当前阶、下一阶实际数值、适用路线和选择后的战斗语义，避免玩家只看到模糊的“变强”。

当前已接入的特色构筑：

- **五相轮转**：多属性攻击按时间切换主属性；棱镜余辉可以保留下一属性，形成“轮转触发反应”的特色路线。
- **破命锋 / 星火裂命**：暴击先改变单体伤害，再通过暴击爆炸转化为范围清场，适合高攻速或多弹道武器。
- **蚀印爆破 / 反应溢流**：属性叠层不只是等待反应，也可以主动积层后引爆，形成状态管理型构筑。
- **踏阵蓄势**：把移动距离转换成下一次攻击的爆发，鼓励玩家绕场、拉扯和主动离开安全区。
- **灵珠炼体 / 四色归一**：灵性球既是经验也是战斗资源，分别提供续航和四色集齐后的全局共鸣。
- **阵内铸身 / 远征令**：围绕光环内外做取舍，让回防、出门、守核形成不同打法，而不是单纯站在中心输出。
- **断魂余爆 / 斩妖契**：击杀链和 Boss 战各有专属收益，支持清群滚雪球与提前挑战山门两种终局路线。
- **溢伤转余劲 / 余劲分裂**：击杀时把溢出伤害传给附近妖物，重击、暴击和高倍率武器可以转化为连续收割。
- **受命·护轮 / 破势 / 借劫还锋**：灵性球生成护盾，承伤转化为反震，破盾清场并通过击杀返还护盾，形成主动防守流。
- **踏影 / 复刻 / 归影**：移动积累距离后留下残影，下一次攻击在残影处复刻，并以命中返还秘术冷却，构成移动—攻击循环。
- **开脉 / 断脉收割**：连续攻击同一目标累积裂痕，重击收割并把裂痕传给附近敌人，形成轻击铺垫、重击收尾的节奏。
- **单相过载 / 余温回响**：坚持单一属性积累过载，满层后触发属性爆发，与五相轮转形成“专精单相”与“切换多相”的路线对立。
- **回锋 / 双相回锋**：远程弹道命中后折返，去程与回程分别结算伤害并可穿透多名敌人，形成弹道走位构筑。
- **收割节奏 / 追魂三响**：击杀返还攻击和秘术冷却，短时间连续击杀三名敌人后额外返还秘术，鼓励主动追杀。
- **淬锋 / 反炼**：属性反应伤害积累为下一击的淬锋值，攻击时转化为额外伤害并在命中点爆发，串起反应、攻击和范围清场。

## 9. 山门挑战与大妖

玩家可以在昼间进入山门 GateZone，持续站定后召唤对应大妖。击败大妖后：

- 对应大妖状态标记为已击败。
- 对应方向从后续刷怪方向中移除。
- 灵性掉落权重会重新计算。

大妖计划：

| 大妖 | 自动波次 | 提前解锁波次 |
| :--- | ---: | ---: |
| 赤裂大妖 | 7 | 5 |
| 翠疫大妖 | 10 | 8 |
| 蓝弧大妖 | 13 | 11 |
| 黄砂大妖 | 16 | 14 |
| 飞升妖王 | 20 | 20 |

第 10 波开始，每名已经出现且尚未击败的大妖提供 1 层山海共鸣，提升敌人的生命、伤害和速度。这里的“山海共鸣”是大妖压力系统，不等同于属性反应。

### 9.1 大妖战斗身份

每名大妖拥有一套可读的专属威胁，半血后进入狂暴阶段，技能间隔缩短并强化预警颜色。所有技能先显示落点或方向，再结算伤害，保证玩家可以通过走位回应。

| 大妖 | 专属技能 | 玩家应对 |
| :--- | :--- | :--- |
| 赤裂大妖 | 赤裂冲锋：锁定方向后高速突进；狂暴后在脚下留下短暂火痕 | 观察红色冲锋线，横向闪避 |
| 翠疫大妖 | 翠疫腐沼：在玩家与灵核附近生成持续毒沼，并追加一枚短时藤瘴 | 离开绿色区域，优先处理压制位置 |
| 蓝弧大妖 | 三相弧矢：向玩家发射三枚扇形水雷弹 | 保持移动，利用弹道间隙切入 |
| 黄砂大妖 | 黄砂流星：围绕玩家布置多枚砂雷；狂暴后增加落点数量 | 不要停在灵核与自己之间，提前换位 |
| 飞升妖王 | 归墟轮：环形落点与追踪雷弹组合；半血后进入终局狂暴 | 以灵核为中心保持旋转走位，护阵用于处理关键波次 |

大妖的状态条固定显示在屏幕上方，技能预警、狂暴状态和灵核受击均通过颜色与文字提示反馈，不依赖调试血量文字。

## 10. 敌人

当前敌人类型：

- **近战妖**：接近玩家并进行接触攻击。
- **箭妖**：远程发射弹体，迫使玩家移动。
- **魔法妖**：远程攻击，受雷火等属性反应影响明显。
- **治疗妖**：远离玩家并治疗附近妖兽，受到毒状态影响。
- **重装妖**：高生命、低移动速度，靠厚重护甲和近身重击压迫玩家；中后期低概率加入。
- **突袭妖**：高移动速度、低生命，快速贴近后进行高频近身攻击；用于打破固定站位。

敌人和大妖都可以携带属性状态。冰、藤会降低移动和行动效率，毒会降低治疗，反应会造成额外伤害和控制。

六类小兵均使用独立的全身透明贴图。基础三类负责教学和常规压力，治疗妖负责后排优先级，重装妖负责改变敌群阵型，突袭妖负责制造侧翼威胁。贴图保持统一的全身比例、脚底基线和东方奇幻材质，但通过武器轮廓、姿态和体型确保缩小到战斗尺寸后仍能一眼区分。

## 11. UI 与失败/胜利

HUD 显示：

- 当前昼夜状态和波次。
- 当前计时。
- 四色灵性球数量。
- 玩家等级和升级经验。
- 当前属性标签与熟练度。
- 光环状态。
- 最近受到的伤害。
- 灵核耐久、护阵剩余时间和主动诀技冷却。

失败条件：玩家生命归零。

胜利条件：第 20 波撑过终局计时，或击杀飞升妖王。

## 12. 角色与发行表现

- 主角在主菜单拥有立绘、法宝图标、武器定位和技能简介预览；进入战斗后使用统一比例的角色精灵与武器挂点。
- 正式第一关使用独立生产场景，中心灵核、菱形四角 Boss 房、四色灵路和安全区均有稳定的画面锚点；区域之间使用连续底图和自然过渡，不使用相互拼接的大块地形贴片。
- 战斗实体使用统一全身角色比例：五名大妖使用全身 Boss 贴图，赤裂、翠疫、蓝弧、黄砂四方势力分别使用近战、治疗、术法、远程四套全身小兵贴图；头像素材仅作为图鉴/HUD 备选，不用于战场实体。
- HUD 提供昼夜、波次、倒计时、灵核与道基血条、四色灵性、属性、诀技、Boss 状态和暂停入口。
- 设置对分辨率和全屏配置做校验，窗口模式支持 1280×720、1600×900、1920×1080。
